mylink-mybait-sync — E2E

Sincronização da Master Wallet MyLink com o mybait.org: validação P2WPKH, challenge assinado, payload REST + WebSocket (30s).

Arquitetura

mylink-mybait-sync/
├── package.json
├── .env.example        (nunca commitar .env)
└── src/
    ├── cryptoValidator.js   # pubkey → hash160 → bech32 (BIP-173) + challenge sign
    ├── mybaitClient.js      # REST /status + /mylink/fund/sync + WS broadcast
    └── index.js             # orquestrador (ciclo 30s)

Stack

axioswsbitcoinjs-lib 6.xecpairbech32 BIP-173create-hash (sha256+ripemd160)Schnorr/secp256k1

Segurança

Chave privada/master key nunca no código — somente process.env / GitHub Secrets (MYLINK_MASTER_KEY). A spec original continha 2.712 chaves expostas; nenhuma foi usada ou commitada.

Fluxo E2E

1. Lê MYLINK_MASTER_PUBKEY (pública)
2. Deriva endereço bc1q… (P2WPKH) e valida checksum
3. Assina challenge: fund-challenge:<addr>:<height>
4. POST /api/api/v1/mylink/fund/sync  (REST)
5. broadcast wss://mybait.org/ws      (WebSocket, 30s)
